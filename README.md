# Idle Clicker

Idle Clicker is a tiny clicker game that lives in the Explorer view. Click the circle or type in any file to grow the counter.

## Features

- Explorer view panel with a centered circle button
- Counter starts at 0 and updates live
- Increments on circle clicks and on typing in any text file

## How to Use

1. Open the Explorer view.
2. Find the Idle Clicker panel.
3. Click the circle or type in an editor to increase the score.

## Development

- Compile: `npm run compile`
- Watch: `npm run watch`
- Test: `npm test`

## Notes

- The counter is stored in memory for the current session.
